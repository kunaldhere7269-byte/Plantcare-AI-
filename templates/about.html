Project Abstract

Crop diseases and nutritional deficiencies cause substantial yield loss among smallholder farmers, school agricultural clubs, and urban terrace gardeners. Conventional diagnostic workflows require access to certified agricultural extension pathologists, which is often logistically inaccessible or cost-prohibitive for rural and semi-urban communities.

PlantCare AI is a full-stack, open-source web application developed as a college Community Engagement Project (CEP). The platform combines accessible web interfaces (HTML5, Bootstrap 5, JavaScript) with a modular Python Flask backend, SQLite database persistence, OpenCV computer vision feature extraction, and dual-mode AI analysis (Live Google Gemini Vision API alongside a transparent Offline Heuristic Knowledge Engine). By democratizing foliar health analysis and promoting Integrated Pest Management (IPM), PlantCare AI fosters community food security and prevents the hazardous overuse of chemical pesticides.

Problem Statement

  • Delayed Diagnosis: Foliar pathogens like Blight and Rust spread exponentially if not caught during initial necrotic spot emergence.
  • Chemical Over-Reliance: Without accurate identification, growers frequently spray broad-spectrum synthetic chemical pesticides, causing ecological harm and pollinator decline.
  • Lack of Historical Record: Gardeners and small farmers rarely maintain systematic logs of symptom recurrence or watering correlations across growing seasons.
  • Misleading Digital Tools: Many mobile apps fabricate certainty on blurry images or claim to measure subterranean soil chemistry from ordinary 2D photos.

Project Objectives

  • Automated Vision Diagnosis: Provide instant foliar health screening from smartphone photographs using modern computer vision and vision-language models.
  • Promote IPM & Ecological Health: Recommend biological, cultural, and lower-risk treatments before toxic chemicals.
  • Longitudinal Growth Tracking: Enable users to store photos, track symptom evolution over time, and compare before/after recovery scans.
  • Honest, Transparent AI: Reject non-plant images, flag blurry photos, avoid fabricating confidence scores, and provide a fully functional offline fallback mode.

System Architecture

PlantCare AI adopts a clean, layered Model-View-Controller (MVC) architecture with clear separation of responsibilities:

Presentation Layer

HTML5, CSS3, JavaScript, Bootstrap 5, Chart.js

Application Layer

Python Flask, Werkzeug, RESTful JSON Endpoints

Vision & AI Layer

Pillow, OpenCV, Gemini Vision API / Heuristic Rules

Persistence Layer

SQLite 3, Indexed Analyses, Local File Storage

Dual-Mode AI Engine Design

A key architectural requirement for this college project is avoiding synthetic hallucinations when API keys are absent. When GEMINI_API_KEY is configured in .env, the application connects to Google's state-of-the-art multimodal vision model. When the API key is omitted, the application runs its transparent Offline Heuristic & Agricultural Pathology Knowledge Base, evaluating real OpenCV chlorophyll ratios, necrotic spot areas, and user context.

File Structure & Component Roles

A concise breakdown for college professors and evaluators:

File / Path Core Technology Responsibility
app.py Flask, Jinja2, Werkzeug Main routing controller, file upload security limits, template rendering, and RESTful API endpoints.
database.py SQLite3, JSON Initializes the database schema, handles CRUD operations, sample record seeding, and computes dashboard statistics.
services/image_processor.py Pillow (PIL), OpenCV Validates uploaded file MIME types, resizes images, creates 400x400 thumbnails, and calculates Laplacian blur variance & HSV chlorophyll/necrotic ratios.
services/ai_analyzer.py REST API, Requests, Heuristics Coordinates AI diagnosis: communicates with Google Gemini Vision API if key exists, or triggers transparent Offline Heuristic Pathology Engine.
static/css/style.css Vanilla CSS3, Tokens Custom agricultural design system, responsive grid, glassmorphic cards, and laser scanning animations.
static/js/analyze.js Vanilla JavaScript (ES6) Client-side file validation, drag-and-drop handler, image preview, animated scan overlay, and asynchronous AJAX submission.
static/js/dashboard.js Chart.js 4.4 Renders dynamic health status doughnut charts, top crop bar charts, and diagnostic activity trends from live database metrics.

Agricultural Ethics & Disclaimers

PlantCare AI is an advisory diagnostic tool developed for educational, academic, and community demonstration purposes. AI models can experience uncertainty with novel pathogens or poor-quality photos. For commercial agricultural operations, always verify disease diagnosis with certified local agronomy extension officers and strictly follow pesticide safety instructions and pre-harvest intervals.
